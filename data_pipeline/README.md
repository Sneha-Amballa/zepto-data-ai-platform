# Data Pipeline Component

This component is responsible for data ingestion, processing, and pipeline automation.

## Structure

- `src/`: Core Python source code for data fetching, transformation, and ingestion.
- `data/raw/`: Store raw, unmodified data files.
- `data/processed/`: Store cleaned and transformed data files.
- `database/`: Databases (SQLite, duckdb, etc.) or database utility scripts.
- `output/`: Processed exports or report files.
