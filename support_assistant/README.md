# Support Assistant Component

This component houses the support assistant (e.g., RAG/LLM-based assistant) scripts and data.

## Structure

- `src/`: Core Python modules for document parsing, embedding generation, prompt management, and agent logic.
- `documents/`: Source documents (PDFs, TXT, markdown, etc.) used as the knowledge base.
- `vector_store/`: Local vector store files or indices (e.g., FAISS, ChromaDB, etc.).
- `output/`: Responses, chat logs, evaluation results, and export files.
