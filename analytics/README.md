# Analytics Component

This component contains Jupyter Notebooks, training/inference code, datasets, and models.

## Structure

- `notebooks/`: Jupyter notebooks for data analysis, exploration, and model prototyping.
- `src/`: Cleaned analytics code and utility modules.
- `dataset/`: Training, testing, and validation data files.
- `models/`: Trained model binaries, serialized parameters, or model metadata.
- `output/`: Generated charts, statistics, reports, and prediction logs.
